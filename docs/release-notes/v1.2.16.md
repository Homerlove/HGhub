## 1.2.16

### 修复
- **吃瓜帖视频不显示（#11）**：帖详情的 `video_url` 由服务端恒返回空，视频地址只由 `POST /api/posts/:id/playback` 下发。新增该接口调用后，吃瓜详情打开即自动起播，多段视频（同一帖拆成 2~6 段）可分段切换并自动续播。

### 变更
- 底栏重做为 iOS 26 液态玻璃悬浮胶囊：不贴边悬浮、液滴弹性跟随滑动、图标充色、按压放大，设计对齐 liuran001/WeChat-LiquidGlass。

### 优化
- 移动端内容底部让位同步加大（40 → 74），首页沉浸视频不被悬浮胶囊压住。

### 构建产物
- Android：arm64 / arm / x86_64 分 ABI 分包
- iOS：未签名 ipa（需自行签名）
- Windows：安装包 + 便携版
- macOS：universal dmg
- Linux：amd64 deb
